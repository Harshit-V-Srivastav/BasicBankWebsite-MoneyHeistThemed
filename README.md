**About Money Heist Banking System**

A themed banking web application inspired by the popular series Money Heist, built using PHP, HTML, CSS, and SQL. The platform provides users with essential banking functionalities through an engaging and visually immersive interface while maintaining efficient transaction management.

**Overview**

Money Heist Banking System combines core banking operations with a unique entertainment-inspired design. Users can manage their accounts, review transaction history, and perform banking activities through a dashboard styled around the iconic Money Heist aesthetic.

**Features**
Secure user account management
Account summary dashboard
Deposit and withdrawal functionality
Fund transfer between accounts
Transaction history tracking
SQL-powered data management
Responsive and intuitive user interface
Money Heist-inspired visual design and branding

**Tech Stack**
PHP
HTML5
CSS3
MySQL / SQL
XAMPP / Apache Server

**How It Works**
Users log in to their banking dashboard.
Account information and balances are retrieved from the database.
Users can perform deposits, withdrawals, and transfers.
Every transaction is securely recorded in the database.
Transaction history is displayed through SQL-powered queries for easy tracking and review.
